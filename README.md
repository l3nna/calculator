# Calculator — Digital Computer From the Ground Up

A calculator built from the ground up as a hands-on exploration of **digital logic, computer architecture, and hardware design**.

The goal isn't just to make a calculator that works — it's to understand **how the hardware actually makes it work**.

I'm designing the system piece by piece, studying the role of each component and building models of fundamental digital circuits along the way. This includes exploring how **flip-flops, registers, input systems, logic circuits, and control signals** work together to store and process binary data.

One of the first components I explored was the **D flip-flop**. Instead of treating the IC as a black box, I built a transistor-level model using **2N7000H60 N-channel MOSFETs** to understand the underlying logic.

---

## Project Architecture

The calculator is being developed as a collection of interconnected digital systems:

* [x] **D Flip-Flop** — studying the fundamental building block of digital memory
* [x] **Input System** — entering and storing binary data
* [ ] **Registers** — storing multi-bit values
* [ ] **Arithmetic Logic** — performing calculations on binary data
* [ ] **Control Logic** — coordinating the different parts of the system
* [ ] **Display** — converting the internal data into a readable output
* [ ] **Complete Calculator** — bringing everything together

##  What I'm Learning

This project is also a way of learning the foundations behind modern computers:

* Digital logic
* Binary representation
* Sequential logic
* Flip-flops and registers
* MOSFET-based circuits
* Memory and data storage
* Arithmetic logic
* Control systems
* Computer architecture

The idea is to start with **individual logic elements** and gradually work toward a complete digital system.

> **From a single bit of memory to a working calculator.**
